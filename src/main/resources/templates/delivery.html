Source project (Maven · Apache NetBeans)

Complete Java project of this simulator: pom.xml, sources, Thymeleaf templates, static resources, JUnit tests, the SEED data-structure classes used and the Dockerfile used for deployment.

Download ZIP

The project archive is not available on this server.

Open and run in NetBeans

  1. Unzip the file and choose File → Open Project on the not-so-naive folder (NetBeans recognizes Maven projects natively).
  2. Use JDK 21 (Project Properties → Build → Compile).
  3. Press Run (main class co.edu.ufps.notsonaive.NotSoNaiveApplication) and open http://localhost:8080.
  4. Run the tests with Test Project (or mvn test).
